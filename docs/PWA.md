# ホーム画面や PC からアプリのように開く

Task Rooms for Dots はブラウザーで使えます。対応する端末では、ホーム画面やデスクトップへ追加して、独立したウィンドウで開くこともできます。このような Web アプリの仕組みを **PWA（Progressive Web App）** と呼びます。

正式なアプリ名は **Task Rooms for Dots** です。小さなホーム画面ラベルなどでは、短縮名の **Task Rooms** が表示される場合があります。

アプリストアからのインストールではありません。追加しなくても、ブラウザーのブックマークから利用できます。**このテンプレートでは、オフラインの会話保存・送信はできません。**

## 自分の端末の手順だけを開く

| 使う端末・ブラウザー | 手順 |
| --- | --- |
| iPhone / iPad の Safari | [ホーム画面に追加](#iphone--ipad) |
| Android の Chrome | [アプリをインストール](#android-の-chrome) |
| Windows / Mac / Linux の Chrome | [PC への追加](#pc-の-chrome) |
| PC の Microsoft Edge | [Edge への追加](#pc-の-microsoft-edge) |
| Mac の Safari（macOS Sonoma 14 以降） | [Dock に追加](#mac-の-safari) |

この表は公式の追加方法への案内です。Task Rooms for Dots の実機対応を検証済みという意味ではありません。**この配布準備では、デスクトップ・iOS・Android への実インストールは未検証です。** OS・ブラウザーの版と管理設定を、使う端末で確認してください。

導入担当の dot は、本体で一往復できた後にこのページを案内し、該当する手順だけを利用者へ渡します。インストール済みかは、アイコンから開き直した結果まで確認します。

## 先に、自分の Site をブラウザーで開く

1. dot が導入後に案内した、自分専用 Site の URL を開きます。GitHub のページではありません。
2. 自分のアカウントでサインインし、架空のタスクと返信が見えることを確認します。
3. URL とアプリ名が自分のものか確認してから、下の手順へ進みます。

画面名は OS、ブラウザー、言語、管理設定によって変わります。表示されないときは、無理に設定を変更せず、ブラウザーで利用してください。

## iPhone / iPad

1. Safari で自分の Site を開きます。
2. 共有メニューを開き、「ホーム画面に追加」を選びます。画面によっては、先にページメニューから「共有」を開きます。
3. 「ウェブアプリとして開く」が表示されたらオンにし、名前を確認して追加します。
4. ホーム画面のアイコンから開き直します。必要なら再度サインインしてください。

iPhone の現行手順は [Apple の iPhone 向け案内](https://support.apple.com/ja-jp/guide/iphone/iphea86e5236/ios)、iPad は [iPad 向け案内](https://support.apple.com/ja-jp/guide/ipad/ipad8f1f7a29/27/ipados/27)を参照してください。iPad では共有後に「表示を増やす」から追加項目を開く場合があります。

## Android の Chrome

1. Chrome で自分の Site を開きます。
2. 右上のメニューから、インストールまたはホーム画面への追加に相当する項目を選びます。現行案内では「インストールしてショートカットを作成」から進みます。
3. 表示された内容を確認し、端末の案内に沿って追加します。
4. 追加されたアイコンから開き、必要ならサインインします。

表示の違いは [Chrome の Android 向け案内](https://support.google.com/chrome/answer/9658361?co=GENIE.Platform%3DAndroid&hl=ja)で確認できます。

## PC の Chrome

1. Chrome で自分の Site を開きます。
2. アドレスバーにインストールのアイコンがあれば選びます。なければ、右上のメニューの「キャスト、保存、共有」から「ページをアプリとしてインストール」を探します。
3. 名前と URL を確認してインストールします。
4. 必要に応じて、OS の通常の操作でタスクバーや Dock に固定します。

詳しくは [Chrome の PC 向け案内](https://support.google.com/chrome/answer/9658361?co=GENIE.Platform%3DDesktop&hl=ja)を参照してください。

## PC の Microsoft Edge

Site を開き、アドレスバーにアプリ追加の表示があれば選びます。ない場合は、右上のメニューから「その他のツール」→「アプリ」→「このサイトをアプリとしてインストール」に相当する項目を探します。追加後の管理は `edge://apps` から行えます。[Microsoft の案内](https://support.microsoft.com/en-US/edge/install-manage-or-uninstall-apps-in-microsoft-edge)

ブラウザーのメニューに項目がない場合でも、ブックマークやショートカットで開く方法は残ります。インストールの表示を出すために、Site を一般公開する必要はありません。

## Mac の Safari

macOS Sonoma 14 以降の Safari では、Web ページを Dock から開くアプリとして追加できます。

1. Safari で自分の Site を開き、ログイン後のアプリ本体を表示します。
2. メニューバーの「ファイル」→「Dock に追加」、または共有ボタンから「Dock に追加」を選びます。
3. 名前と URL を確認して「追加」を選びます。
4. Dock のアイコンから開き直し、必要ならサインインします。

必要条件と画面の違いは [Apple の Mac 向け案内](https://support.apple.com/ja-jp/104996)で確認できます。追加後も、所有者限定のアクセス制限は保ちます。

## 開き直せたら、起動方法を確認する

- 追加したアイコンから自分用 Site が開く。
- 本人としてサインインし、架空のタスク・返信・画像を確認できる。
- ブラウザーで見ていた新しい投稿が同じ Site に反映される。

dot が実機を操作できない場合は、本人が確認した結果を記録します。PC の画面を狭くしただけでは、iPhone / Android での確認にしません。PC とスマートフォンを使うなら、端末ごとに確かめます。

追加メニューが見つからない場合は、まず通常の Safari / Chrome / Edge で開いているかを確認してください。ほかのアプリ内のブラウザーでは表示が異なることがあります。ブラウザー利用のままでも始められます。設定をリセットしたり Site を公開したりして解決しようとしません。

## 返信の端末通知は、別途許可する

ホーム画面への追加だけでは、通知は有効になりません。

1. 導入担当の dot に、任意の Web Push 設定を用意したか確認します。
2. アプリの「返信の通知」を開き、自分で通知を受け取る操作を選びます。
3. OS・ブラウザーが表示する許可画面で、内容を確認して許可します。
4. 新しい架空の返信を 1 件作り、端末へ実際に届くか確認します。

iPhone / iPad の Web Push は、ホーム画面アプリ向けに iOS / iPadOS 16.4 から導入されています。通知やバッジの表示は、OS・ブラウザーの対応と設定に依存します。[WebKit の説明](https://webkit.org/blog/13878/)

通知がなくても、アプリを開いて返信を確認できます。常時実行、即時返信、すべての端末での通知は保証していません。困った場合は[端末通知の切り分け](TROUBLESHOOTING.md)へ進んでください。

## アイコンを消しても、Site の保存データは別に残る

PWA やショートカットの削除は、通常、端末上の起動方法を消す操作です。Site、D1、R2 のデータ削除とは別です。アプリの利用を終了する場合は、購読と通知を停止し、保存データと Site をどう扱うかを別途確認してください。

公式案内の確認日：2026 年 10 月 25 日。提供元の案内と自分の端末の表示が異なる場合は、導入時点の公式手順を優先してください。
