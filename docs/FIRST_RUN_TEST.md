# 別アカウントで、最初の導入を試す

**このページは、まだ実施していないテストの手順です。** 配布元のローカル検査や同一所有者の検証用 Site での結果を、別アカウントでの導入成功に置き換えません。

試す人が自分の dot に [短い導入文](../COPYPASTE_INSTALL_PROMPT.md) と対象リポジトリを渡します。自分が管理する新しい非公開 Site・空の DB・空の画像ストレージだけを使い、作者や他人のデータ・鍵・設定をコピーしません。既存アプリは変更しません。

## まず、空のアプリで一往復する

1. dot が [AGENT_SETUP.md](../AGENT_SETUP.md) に従って、対象版の安全確認と利用条件を確認します。使えない機能があれば止め、必要な権限を説明します。
2. 本体 7 工程を進め、ログインや設定に必要な本人の操作を、その都度行います。暗号化鍵・購読・通知は短い依頼だけで一括承認した扱いにしません。
3. 「サンプルの買い物メモ」などの架空タスクを作り、「テスト投稿です」と送ります。自分の dot から同じ部屋へ返信が返り、投稿の待ち状態が解消されることを確認します。
4. 個人情報のない図形の画像を 1 枚添付し、プレビューと読み取りを確認します。実際の人物写真、業務書類、位置情報を含む画像は使いません。
5. 同じ返信の再試行で重複しないこと、未認証では内容や画像を読めないことを [チェックリスト](DEPLOYMENT_CHECKLIST.md) で確認します。他人のアカウントを無断で試したり、認証情報を借りたりしません。
6. 普段使う端末で開き直します。希望すれば [PWA 手順](PWA.md) に従い、アイコンからの再起動も確認します。PC とモバイルを希望するなら、それぞれ試します。

自動返信の購読は、手動の一往復とは別に承認・配送・実返信まで確認します。端末通知と履歴取り込みは、本人が希望する場合だけ別に進めます。通知が来たことだけでは、自動返信を確認したことになりません。

## 途中で止まったら、何を待っているか確認する

進捗は「本体 3/7 工程完了／実施中の工程／待ち理由／次の操作」の形で受け取ります。工程が増えない時間があっても、時間の割合が止まっているという意味ではありません。

- ログイン・承認待ち：必要な画面と操作を dot に確認します。パスワードや秘密鍵はチャットへ貼りません。
- サービス処理待ち：完了結果を確認してから次へ進みます。結果不明のまま作成や投稿を繰り返しません。
- 権限・検証エラー：止まった工程を記録し、公開範囲や認証を緩めずに原因を確認します。

作業中の報告は数分ごとを目安にしますが、ツール実行や接続状態により届かない場合があります。音沙汰がない場合は「今の完了数・作業・待ち理由を教えて」と聞けます。再開時は既存の状態を確認し、重複作成を避けます。
